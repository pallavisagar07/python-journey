# 📊 Student Performance Analysis using NumPy

A beginner-friendly data analysis project built using **Python and NumPy** to analyze student performance, subject scores, attendance, and overall class performance.

## 🎯 Project Objective

The main goal of this project was to practice NumPy concepts by applying them to a real dataset instead of only working with theoretical examples.

## 📁 Dataset

The dataset contains performance information for **20 students**.

### Columns

* `Student_ID` – Unique ID of each student
* `Student` – Student name
* `Math` – Math score
* `Science` – Science score
* `English` – English score
* `Computer` – Computer score
* `Attendance` – Attendance percentage

## 🛠️ Tools & Technologies

* Python
* NumPy
* Pandas
* Jupyter Notebook

## 🔍 Analysis Performed

The project covers:

* Converting tabular data into NumPy arrays
* Understanding array shape, dimensions, and size
* Indexing and slicing
* Calculating mean, median, minimum, maximum, standard deviation, and variance
* Calculating student-wise average scores
* Categorizing students based on performance
* Analyzing attendance and performance
* Finding top and bottom performers
* Subject-wise performance analysis
* Finding students above the class average
* Using NumPy functions such as:

  * `np.mean()`
  * `np.median()`
  * `np.min()`
  * `np.max()`
  * `np.std()`
  * `np.var()`
  * `np.where()`
  * `np.argmax()`
  * `np.argmin()`
  * `np.argsort()`

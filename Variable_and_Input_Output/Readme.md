Variables and Input/Output in Python

📌 Objective

Learn how to store data using variables and interact with users through input and output statements in Python.

---

📖 What are Variables?

A variable is a named container used to store data in memory. The value of a variable can be changed during program execution.

Example

name = "Pallavi"
age = 20
height = 5.2

---

📖 Input in Python

The "input()" function is used to take input from the user. By default, it returns the input as a string.

Example

name = input("Enter your name: ")
print(name)

Taking Integer Input

age = int(input("Enter your age: "))
print(age)

Taking Float Input

height = float(input("Enter your height: "))
print(height)

---

📖 Output in Python

The "print()" function is used to display output on the screen.

Example

print("Hello, World!")

Printing Multiple Values

name = "Pallavi"
age = 20

print("Name:", name)
print("Age:", age)

---
🎯 Key Concepts

- Variables store data.
- Variable names should be meaningful.
- "input()" takes user input.
- "print()" displays output.
- "input()" returns a string by default.

---
🛠️ Skills Learned

- Creating variables
- Taking user input
- Displaying output

---

📚 Conclusion

Variables and input/output are the foundation of Python programming. Mastering these concepts makes it easier to build interactive programs and prepares you for learning conditions, loops, functions, and other advanced Python topics.

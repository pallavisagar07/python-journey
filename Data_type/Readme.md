What are Data Types?

In Python, data types define the type of value a variable can store and determine the operations that can be performed on it. Python provides several built-in data types to work with different kinds of data efficiently.

Data Types Covered

- Integer ("int") – Stores whole numbers.
- Float ("float") – Stores decimal numbers.
- String ("str") – Stores text or characters.
- Boolean ("bool") – Stores "True" or "False".
- List ("list") – An ordered, mutable collection of items.
- Tuple ("tuple") – An ordered, immutable collection of items.
- Set ("set") – An unordered collection of unique elements.
- Dictionary ("dict") – Stores data in key-value pairs.

# Python Conditional Statements Practice

## 📌 Overview
This repository contains practice programs on Python Conditional Statements. These programs are designed to help beginners understand how decision-making works in Python using `if`, `if-else`, and `if-elif-else`.

## 🎯 Topics Covered
- if statement
- if-else statement
- if-elif-else statement
- Comparison operators
- Logical operators (`and`, `or`, `not`)

## 📚 Practice Questions
Some of the problems included are:
- Positive, Negative, or Zero
- Even or Odd
- Largest of Three Numbers
- Leap Year Checker
- Grade Calculator
- Voting Eligibility
- Triangle Type Checker
- ATM Withdrawal
- Restaurant Bill Calculator

## 🛠️ Technologies Used
- Python 3
- Jupyter Notebook

## ▶️ How to Run
1. Download or clone this repository.
2. Open Jupyter Notebook or JupyterLab.
3. Open the notebook.
4. Run each cell to practice the programs.

## 🎓 Learning Outcome
After completing these programs, you will be able to:
- Write decision-making logic using conditional statements.
- Use comparison and logical operators effectively.
- Solve real-world problems using Python conditions.
